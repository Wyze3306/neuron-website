🧠 Supprimer mon compte NEURON

Vous pouvez supprimer votre compte et toutes vos données à tout moment.

⚠️ Attention : Cette action est irréversible. Toutes vos données (progression, statistiques, historique, abonnement) seront définitivement supprimées.

Comment supprimer votre compte :

  1. Ouvrez l'application NEURON
  2. Allez dans Paramètres → Compte
  3. Appuyez sur "Supprimer mon compte"
  4. Confirmez la suppression
